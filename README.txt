# Wildly — Animal Discovery Website

A responsive animal and wildlife website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website content and sections
- `style.css` — layout, responsive styling, and image backgrounds
- `script.js` — mobile navigation, animal filters, favourites, fun facts, and demo newsletter form

## Run
1. Extract the folder.
2. Open `index.html` in your browser, or open the folder in VS Code and use Live Server.
3. An internet connection is needed for the Google Fonts and Unsplash background photos.

Note: The newsletter form is a front-end demo and does not store or send email addresses.
